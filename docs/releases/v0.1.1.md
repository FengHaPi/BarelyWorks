# v0.1.1 Alpha

发布日期：2026-08-25

## 发布摘要

v0.1.1 完成 AI Video Studio V1 的本地媒体生产闭环：从 Updream 人工投递包、生成视频导回和九维人工质检，一直到 FFmpeg 粗剪、SRT 字幕、终审与交付文件下载。文字生产仍由本地 Skill 驱动 Codex，付费视频 API 保持关闭。

## 主要更新

- 新增可恢复的项目归档、已归档列表和恢复入口，保留项目文件与历史版本。
- 新增项目便携 FFmpeg/ffprobe 发现、能力预检、安装脚本和真实媒体自检。
- 新增生成视频收件箱导入、哈希去重、ffprobe 元数据和起始/中段/结束三点关键帧。
- 新增九维人工质检、版本化审核结论和完整质检证据界面。
- 新增 H.264/AAC 粗剪、SRT 字幕、终审批准/驳回，以及 MP4、SRT、Markdown 报告下载。
- 新增横版、竖版和方形 480p 成片输出规格，服务端拒绝短边低于 480px 的项目规格。
- 将成片输出规格与供应端生成清晰度解耦；清晰度设置不进入 Codex 或 H3 提示词。
- 新增 Skill 契约 EVAL、媒体自检和 Phase 5 端到端发布门禁。

## 验证结果

- 10 个测试文件、43 项测试通过。
- TypeScript 类型检查和完整生产构建通过。
- FFmpeg 9.0.1、ffprobe、libx264、AAC 能力验证通过。
- 合成媒体已通过导回、三点关键帧、九维审核、1080p 粗剪、SRT、终审和下载闭环。

## 当前边界

- 真实 Updream 多镜头视频的视觉质量与完整项目交付仍待人工验收。
- Updream 仍是人工生成端，不依赖未经验证的私有 API 或无人值守网页自动化。
- MiniMax、Runway、Seedance 等付费视频 API 尚未接入。
- FFmpeg 二进制、项目素材、数据库、日志和生成视频不包含在 GitHub 源码包中。

完整变更记录见仓库根目录的 `CHANGELOG.md`。
