# v0.2.0 Alpha · 付费生成安全重构

本版本不承诺生成模型绝对不犯错，但把可确定发现的复杂度、物理矛盾、提示词过载和历史版本污染全部前移到付费视频生成之前。

## 核心变化

- 大纲和剧本先做容量计算；目标时长放不下时直接阻止推进并给出最低可靠时长。
- 导演脚本逐镜头限制剧情 Beat、运镜、事件门和高风险任务，超限必须拆镜。
- 手机朝向、不可见屏幕细节、镜面拓扑、群体同步动作、雾面镜清晰成像、矛盾声音时间线等由程序硬检查。
- H3 仅接收紧凑执行简报；不再重复输入完整上游数据。
- Codex 文字模型固定且可见；H3 模式指南不再重复加载。
- 结构一致性、模型可执行性、实片视觉审核拆成三个独立状态。
- 旧投递包按 `model-executability-v2` 自动失效。

## 兼容与迁移

- 项目和历史文件不删除。
- 旧导演脚本、分镜和 H3 投递包仍可查看，但必须按新规则生成新版本后才能进入付费投递。
- 调整项目总时长时保留全部历史，工作流回到大纲入口。

## 验证

- TypeScript 类型检查通过。
- 服务端 122 项测试通过。
- UI 35 项测试通过。
