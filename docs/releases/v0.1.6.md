# AI Video Studio v0.1.6 Alpha

发布日期：2026-08-25

## 参考图工作流

- 本地 Codex 根据资产定义生成中文提示词、英文提示词、负面提示词、构图要求和连续性锁定项。
- 每次生成均创建新提示词版本，保存于 `prompts/assets/<ASSET-ID>/vNNN/`，旧版本不会覆盖。
- 资产卡片可直接复制完整提示词，也可继续上传已有参考图。
- 人物、场景和其他视觉资产的完整设计字段在正常流程中直接展示。

## 图像 Provider 预留

真实图片输出通过独立 `ImageGenerationProvider` 接口完成。默认实现保持未配置和关闭，因此不会调用付费服务。未来接入 OpenAI Images、ComfyUI 或其他供应端时，不需要改动资产提示词、UI 或项目文件结构。

当 Provider 启用后，返回图片仍必须通过格式、像素解码、大小、路径与 SHA256 校验，成功后才写入项目并绑定当前资产。
