# AI Video Studio v0.1.3 Alpha

发布日期：2026-08-25

## 版本目标

减少正常生产流程中的重复确认。程序自动完成可确定、可恢复、不会产生外部费用的本地步骤；用户只负责真正需要判断的内容审核、云端视频生成与最终交付。

## 新流程

1. 审核并批准当前文字产物后，下一阶段草案自动生成并停在审核页。
2. 批准最终分镜后，素材锁定与初始化包自动完成，页面进入生成中心。
3. 生成中心可一键补齐所有缺失且预检通过的 H3 镜头包，已有版本不重复生成。
4. 用户在外部平台生成视频并放入本地收件箱，扫描导入后逐镜头快速审核。
5. 最后一个镜头通过时自动生成本地粗剪；最终成片仍需用户明确批准后才创建交付版本。

## 安全边界

- 不自动批准 AI 生成的文字、人物设定、镜头或成片。
- 不自动操作 Updream，不调用未配置的付费视频 API。
- 不覆盖历史版本；批量任务部分失败时保留已成功结果。
- 不绕过资产、连续性、H3 预检、媒体能力和文件哈希门禁。
