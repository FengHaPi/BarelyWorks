# v0.1.2 Alpha

发布日期：2026-08-25

## 发布摘要

v0.1.2 将 AI Video Studio 从“所有专业信息同时展示”改为两层工作流。默认界面采用大字号，只呈现当前内容、状态和唯一下一步；遇到异常或需要修改时，再进入“详细处理”查看版本、证据、诊断和修复工具。

## 主要更新

- 新增默认简洁流程和全局“发现问题 / 详细处理”切换。
- 页面或请求报错时自动打开详细处理，错误不会被隐藏。
- 整体放大正文、按钮、表单、标签和技术信息字号。
- 项目总览、文字阶段、生成中心、质量审核和成片交付均减少默认面板数量。
- 质量审核支持一键通过或按问题类型驳回当前镜头；其他已通过镜头和旧视频保持不变。
- 多余文字与水印问题自动生成禁止字幕、标题、UI、Logo、水印和乱码的重试要求。
- 全部镜头通过后直接展示粗剪入口，并明确进入成片终审。
- 成片批准后自动进入独立完成页；已交付项目重新打开时也不再停留在九阶段全完成总览。

## 当前边界

- Updream 仍为人工生成端；程序不会伪装成已经接入的视频生成 API。
- 详细模式继续保留不可变历史、哈希、Skill 来源、九维审核和媒体诊断能力。
- 简洁模式只调整信息层级，不降低文件、版本、审批和媒体校验门禁。

## 验证

- TypeScript 类型检查、服务端与 UI 回归测试、生产构建全部通过。
- 本地预览验证默认简洁流程、详细模式切换、快速审核和粗剪入口。
