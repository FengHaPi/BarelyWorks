# Updream 当前能力检查清单

V1 把 Updream 视为人工生成端，不视为稳定 API。以下项目在真实投递前逐项确认并记录日期：

- [ ] 用户可正常登录，未通过自动化绕过验证码或权限。
- [ ] 可以新建或打开目标项目。
- [ ] 角色、场景、道具和风格素材的上传控件已人工验证。
- [ ] 当前模型、时长、画幅、分辨率选项已人工核实。
- [ ] 引用素材数量上限已核实；未知时保持 `null`。
- [ ] 提示词输入和中文内容可完整保留。
- [ ] 生成结果能以 `S003_V01.mp4` 形式下载并保留版本。
- [ ] 平台规则允许当前人工辅助方式。
- [ ] 网页 DOM、登录和上传流程变更已记录。

确认记录不得包含 Cookie、Token、API Key 或个人登录凭据。
