# 本地项目与备份策略

- `projects/<project-id>/source/original-v001.txt` 是不可变原件，创建时使用独占写入。
- `project.yaml` 采用临时文件写入后原子替换，SQLite 使用 WAL。
- 已批准产物只新增版本；上游修改使下游标记为过期，但不删除历史。
- `data/`、`projects/` 和生成素材默认不提交 Git。
- 备份目标必须位于独立目录或磁盘；执行备份前检查可用空间与目标路径。
- “删除项目”执行可恢复归档：从活动项目列表隐藏，并记录归档时间，但保留项目目录、原始内容、素材、镜头、生成记录与全部版本。
- 归档项目可从顶部“已归档”入口恢复。当前不提供永久删除能力，避免误删本地生产资料。
